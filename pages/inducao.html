Provas por Indução

Indução simples, forte e estrutural em algoritmos

Por que provar?

Testar um algoritmo com alguns vetores não garante que ele funcione para todos os casos. A prova por indução é a ferramenta padrão para mostrar que uma propriedade vale para qualquer entrada — por exemplo, que um algoritmo de ordenação sempre produz um vetor ordenado.

Indução matemática simples

Para mostrar que uma proposição P(n) vale para todo n ≥ inicial:

  1. Passo base — mostrar que P(inicial) é verdadeira.
  2. Passo indutivo — assumir P(k) e mostrar que P(k+1) também é verdadeira.

Se ambos valem, P(n) é verdadeira para todo n ≥ inicial.

Exemplo — soma de um vetor

Considere o código abaixo, que soma os elementos de uma lista:

int soma = 0;
for (int i = 0; i < n; i++) {
  soma += lista[i];
}

Proposição P(n): após n iterações, soma contém a soma dos n primeiros elementos.

Passo base (n = 0): nenhuma iteração, soma = 0. Verdadeiro.

Passo indutivo: suponha P(k) — após k iterações, soma = Σ lista[i] para i de 0 a k-1. Ao executar mais uma iteração, somamos lista[k]:

Σ(i=0..k-1) lista[i]  +  lista[k]  =  Σ(i=0..k) lista[i]

Ou seja, P(k+1) também vale. Por indução, P(n) vale para todo n ≥ 0.

Indução forte

Às vezes, provar P(k+1) precisa de mais do que apenas P(k) — pode ser necessário assumir todos os casos anteriores. Nesse caso usamos a indução forte:

  1. Passo base — P(inicial) é verdadeira.
  2. Passo indutivo — assumir P(inicial), P(inicial+1), …, P(k) e mostrar P(k+1).

A indução forte é mais comum em algoritmos de divisão e conquista, como quicksort, mergesort e busca binária — onde o problema se decompõe em subproblemas que não são k+1 → k, mas sim n → n/2.

Exemplo — busca binária

Proposição P(n): a busca binária retorna corretamente o índice do alvo (ou -1) em qualquer vetor ordenado de tamanho n ≥ 1.

Passo base (n = 1): um vetor com um único elemento. A busca compara uma vez e retorna o resultado. Verdadeiro.

Passo indutivo: suponha que P(j) vale para todo 1 ≤ j ≤ k. Para um vetor de tamanho k+1, a busca compara com o meio e descarta metade. O subvetor restante tem tamanho j com 1 ≤ j ≤ ⌊(k+1)/2⌋ ≤ k. Pela hipótese, P(j) vale — logo o resultado é correto. P(k+1) também vale.

Por indução forte, P(n) vale para todo n ≥ 1.

Indução estrutural

Quando a estrutura é definida recursivamente — como listas encadeadas e árvores —, a indução matemática simples não basta. É necessário raciocinar sobre como a estrutura é construída, e não sobre números.

A prova por indução estrutural segue o formato:

  1. Passo base — a propriedade vale para o caso base da definição (por exemplo, a lista vazia NULL).
  2. Passo recursivo — assumindo que a propriedade vale para uma estrutura menor, mostrar que ela também vale para a estrutura construída a partir dela.

Definição recursiva de lista

Lista ::= NULL
       |  Célula(elemento, Lista)

Traduzindo: uma lista ou é vazia, ou é uma célula com um elemento e uma referência a outra lista (possivelmente vazia).

Exemplo — comprimento da lista

int tamanho(Lista* l) {
  return (l == NULL) ? 0 : 1 + tamanho(l->prox);
}

Proposição P(L): tamanho(L) retorna o número exato de células de L.

Passo base — L = NULL: tamanho(NULL) = 0. Correto.

Passo recursivo: seja L' = Célula(x, L), construída a partir de uma lista menor L. Pela hipótese, tamanho(L) retorna corretamente o tamanho de L. Então tamanho(L') = 1 + tamanho(L) — uma célula mais o tamanho do restante. Coincide com o número real de células de L'.

Por indução estrutural, a propriedade vale para toda lista L.

Regra prática: se provar P(k+1) só precisa de P(k), use indução simples. Se a redução for n → n/2 ou n → n-1 (mais de um caso), use indução forte. Se a estrutura não for numérica — listas, árvores —, use indução estrutural.
