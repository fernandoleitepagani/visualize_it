Número de comparações entre registros

Para todos os casos — melhor, médio e pior — o Selection Sort executa exatamente a mesma quantidade de comparações entre registros.

contagem
      for (i = 0; i < (n - 1); i++) {
            menor = i;
            for (j = (i + 1); j < n; j++) {
              if (vetor[j] < vetor[menor])        
              menor = j;
            }
            swap(menor, i);
      }

c(n) = n−2 Σ i = 0 (n − i − 1)
i 0 1 2 … n−2
c(i) = (n − (i + 1)) n−1 n−2 n−3 … 1

O Algoritmo de Seleção realiza Σ0 ≤ i ≤ n−2 (n − i − 1) comparações entre registros. Agora, mostraremos a fórmula fechada para esse somatório.

fórmula fechada
0 ≤ i ≤ n−2 Σ (n − i − 1) = n(n − 1) − (n − 2)(n − 1) 2 − 1 · (n − 1)
= 2n(n − 1) − (n − 2)(n − 1) − 2(n − 1) 2
= 2n² − 2n − (n² − 3n + 2) − 2n + 2 2
= n² − n 2 = Θ(n²)
